개인정보처리방침

이 방침은 「늙은 나그네 업로드 도구」(이하 "도구")가 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 수집하는 데이터

도구는 운영자 본인의 Google 계정으로 YouTube에 로그인할 때 발급되는 OAuth 액세스 토큰과 리프레시 토큰만 저장합니다. 요청하는 권한은 YouTube 업로드(youtube.upload)와 채널 읽기(youtube.readonly)입니다. 그 외 개인정보(이름, 이메일, 연락처, 시청 기록 등)는 수집하지 않습니다.

2. 사용 목적

토큰은 운영자 채널에 영상을 올리고, 올린 영상 목록을 확인하는 데만 씁니다.

3. 저장과 보호

토큰은 운영자의 개인 PC 로컬 파일에만 저장되며 외부 서버로 전송하지 않습니다. 소스 저장소에는 포함하지 않습니다.

4. 제3자 제공

어떤 데이터도 제3자에게 제공·판매·공유하지 않습니다. 데이터는 Google YouTube API 서버와만 주고받습니다.

5. 보관과 삭제

토큰은 운영자가 로컬 파일을 삭제하면 즉시 사라집니다. 또한 Google 계정 권한 페이지에서 언제든 접근을 철회할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책

도구의 Google API 정보 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다. 또한 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

7. 변경

방침이 바뀌면 이 페이지에 반영하고 수정일을 갱신합니다.

Summary (English): This tool stores only the owner's own OAuth tokens, locally on the owner's PC, to upload videos to the owner's YouTube channel. No other personal data is collected, and nothing is shared with third parties. Access can be revoked at any time at myaccount.google.com/permissions.
